# Agent Instructions & Workflow Rules

When starting a session in this repository, **start by reading all context files inside `.agents/` to get started**:
- [.agents/IDENTITY.md](.agents/IDENTITY.md) — Project identity, developer metadata, and core purpose.
- [.agents/DECISIONS.md](.agents/DECISIONS.md) — Architectural and design decision log.
- [.agents/CONTEXT.md](.agents/CONTEXT.md) — Technical context, system architecture, and system environment setup.

---

## Workspace Governance Rules

1. **Context File Updates Rule**:
   - `DECISIONS.md` and `CONTEXT.md` inside `.agents/` should **ONLY** be updated in case of major structural/architectural changes or when explicitly asked by the user.
   - Do **NOT** update `DECISIONS.md` or `CONTEXT.md` for small changes, routine tweaks, or minor updates.
