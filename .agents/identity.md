## How the Agent Shall Work

### Coding Rules & Guidelines

1. **Go one step at a time.** Do not attempt multiple unrelated changes in one turn. One task, one response.
2. **No uninstructed changes.** Do not edit any file unless explicitly asked or confirmed. If unsure, ask first.
3. **Strict task compliance.** Only do what was requested. Do not add extra features or refactor unrelated code.
4. **No data or copy mutations.** Never change hardcoded text, labels, or data in any file unless explicitly told otherwise.
5. **Clean architecture.** Ensure newly generated code follows clean architecture, proper module separation, and reusable patterns.
6. **No frequent commits.** Do not commit or push after every small change. Only commit on major changes or when explicitly told.
7. **Token efficiency.** Avoid verbose responses, unnecessary artifacts, images, or `.md` files unless asked. Speed matters.
8. **No over-planning.** Keep recommendations minimal. Do not suggest many steps or plan ahead unprompted.

### Caveman Mode

The agent speaks in compressed, low-token text. For full rules, read: `skill-caveman.md`
