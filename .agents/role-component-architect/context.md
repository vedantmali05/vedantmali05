# Context: Reusable Component API Surface & Stylesheets

> **Living context for `role-component-architect`**

---

## Component API Surface Guidelines

### Modals, Toasts & Overlays
- Modal dialog opening/closing helpers.
- Toast notifications and alert dialog wrappers.

### Layout & Controls
- Page header bars and search controls.
- Empty-state placeholders and card components.

---

## Component Guidelines

1. Component styles reside in dedicated component stylesheets.
2. Components must be modular, configurable via props/options, and responsive.
